04 / HTTP API

API Contract.

A unified interface to seamlessly compare traditional Machine Learning models against Google's Gemini LLM.

POST /ai-tool/api/process

JSON body:

{
  "text": "string (required)",
  "mode": "summarize | translate | tone | document | ticket",
  "use_ai": "boolean (toggles between local ML and Gemini API)",
  "target_lang": "optional for translate",
  "query": "required for document"
}

Returns { "success": true, "result": "…" } or an error object.

Architecture & Models

  • Summarize: TF-IDF Extraction vs Gemini 3 Flash
  • Translate: Google Translate API vs Gemini Translation
  • Tone: TextBlob Lexicon vs Gemini Sentiment
  • Document: Okapi BM25 Ranking vs Gemini RAG
  • Ticket: Naive Bayes Classifier vs Gemini Zero-Shot

Related routes

  • Studio UI — calls this endpoint from the browser.
  • Presets — client-only; could POST the same payload after loading a preset.
